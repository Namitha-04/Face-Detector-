# Real-Time Face Detection using OpenCV

A beginner-friendly real-time face detection project built using Python and OpenCV.

## Features
- Real-time face detection using a webcam.
- Haar Cascade Classifier for frontal face detection.
- Grayscale image processing.
- Bounding boxes around detected faces.

## Technologies Used
- Python
- OpenCV
- Haar Cascade Classifier

## Installation

Install OpenCV:

```bash
pip install opencv-python
```

## Run the Project

```bash
python faceDetector.py
```

Press `Q` to exit the webcam window.

## How It Works

The program captures video frames from the webcam, converts them into grayscale, and uses a pre-trained Haar Cascade classifier to detect faces.
